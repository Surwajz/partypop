# Asset Guide

Place optional replacement art under `public/assets/` using these exact filenames. The app falls back to CSS shapes or existing files when assets are missing.

| Filename | Recommended size | Ratio | Notes |
| --- | --- | --- | --- |
| `backgrounds/home-bg.png` | 1920x1080 or larger | 16:9 | Opaque cozy home/date-night background |
| `backgrounds/questions-bg.png` | 1920x1080 | 16:9 | Opaque writing-table or question backdrop |
| `backgrounds/truth-bg.png` | 1920x1080 | 16:9 | Opaque midnight-purple mood image |
| `backgrounds/dare-bg.png` | 1920x1080 | 16:9 | Opaque burgundy/gold action mood image |
